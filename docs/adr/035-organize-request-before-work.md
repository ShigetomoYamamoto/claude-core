# ADR-035: 新しい作業の依頼は、着手前に整理して見せ、OK を待つ

**ステータス**: accepted

**日付**: 2026-11-25

**関連**: 旧スキル `3-line-contract`（本 ADR で削除する）、[ADR-022](./022-autorun-flow-out-of-always-loaded-rules.md) の常時ロードのコスト意識

## コンテキスト

- 直近 30 日のユーザー自身のセッションを振り返った。手書きの作業依頼 570 件のうち、目的・対象（誰が使うか）・合格基準の 3 つがそろっていたのは 7% だった。対象の欠けが約 80%、合格基準の欠けが 77% だった。
- 一方、材料を渡すときは、その使い道も書いていた割合が 91% だった。
- 旧スキル `3-line-contract` は、30 日間で 0 回しか呼ばれていなかった。スキルは呼ばれたときにだけ読み込まれるので、呼ぶことに頼る方式は働かない。
- ユーザーは、自由に話し、資料の場所を指し示す形で依頼することを好む。
- Claude Code の公式ベストプラクティス（code.claude.com/docs/en/best-practices、2026-11-25 確認）は、常時読み込む指示を短く保つことと、Claude が自分で実行できる確認手段を与えることを勧めている。

## 検討した選択肢

- **A. `3-line-contract` を 5 項目に広げ、起動の短いルールだけ足す** — 却下。スキルが読み込まれることに頼るままで、手順も 1 つ増える。ユーザーは全項目を常時有効にしたい。
- **B. 整理を見せたうえで、仮の前提のまま着手する** — ユーザーが却下。OK が出るまで止まる。
- **C. プロジェクトの CLAUDE.md に書く** — 却下。秘書の作業と開発のセッションの両方に効かせる必要がある。
- **D. `rules/collaboration-style.md` に新しい節を足す（採用）** — OK まで止まる。指された資料は読み取りだけで探す。省略の条件を置く。`3-line-contract` は削除する。

## 決定

- `rules/collaboration-style.md` に節「Organize the request before starting work」を足し、「Clarify vs. assume」の最初の項目に、新しい作業はこの節を通す例外を 1 行足す。
- 対象は、ユーザーが新しい作業（調査・文書やメッセージの下書き・設計や設定の変更・実装）を自由に話したり書いたりしたとき。
- 手順は次のとおり。
  1. 指された資料（スレッド・ページ・ファイル・URL）を読み取りだけで探し、実際の文書を特定する。編集や外部への書込はしない。
  2. 目的・対象・合格基準（Claude が自分で確かめられる形）・材料と用途・不明点（最大 3 つ、各案つき）を、ユーザーが確認できる提案の形で日本語で見せる。
  3. 「この整理で進めてよいですか？」と 1 つだけ聞いて止まる。OK で着手する。訂正されたらその行を直し、目的か合格基準が変わったときだけ全体を見せ直す。
- 省略する場合: 「そのまま進めて」と言われたとき、または目的・対象・確かめられる合格基準がすでに示されているとき。この場合は 1 行で復唱して進める。
- 対象外: 1 手の操作（マージ、状況更新、承認済みの文面の投稿）、作業の途中の回答や承認、固有のゲートを持つスラッシュコマンドと `/autorun`。
- `skills/3-line-contract/` を削除し、README と `docs/requirements.md` の記載を直す。

## 結果

### Positive

- 目的・対象・合格基準が、依頼のたびに着手前にそろう。呼び出しに頼らない。
- ユーザーは、いつもの話し方のまま依頼できる。

### Negative

- 新しい作業の依頼で、往復が 1 回増える。省略の条件と対象外で抑える。
- `rules/` は毎回全文が読み込まれるので、常時のコンテキストが少し増える。

### 運用上の影響

- `/autorun` と固有のゲートを持つスラッシュコマンドは対象外にし、ゲートごとの判定者が 1 つのままになるようにする。
- 実機の `~/.claude/skills/3-line-contract` は、次回の更新で `installer.py` が REMOVE_STALE として削除する。
- 別リポジトリの loop-engineering スキルには `3-line-contract` への言及が残っている。別途直す。
- 効果は、2026-12-02 ごろに同じ方法で測り直す。
